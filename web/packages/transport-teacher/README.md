# Teacher Transport Types

Generated transport-only declarations for the Teacher/Controller OpenAPI
operation allowlist. The canonical source is
`contracts/openapi/openapi.yaml` at OpenAPI info version `0.8.0`; generation uses
`openapi-typescript@7.13.0` through
`scripts/contract-validation`.

Regenerate from `scripts/contract-validation` with:

```bash
npm run generate:transports
```

Do not hand-edit `src/index.d.ts` or use these declarations as domain or
application types.
