# Contract Validation Harness

Private repository tooling that validates the canonical OpenAPI document and
standalone JSON Schemas. It also verifies deterministic, role-scoped frontend
transport declarations generated by `openapi-typescript`.

```bash
npm ci
npm test
```

Canonical inputs remain under `../../contracts/`. The dereferenced bundle and
role subsets under `.tmp/` are disposable, ignored tooling outputs and are not
contract authority.

Dependency audit note (`2026-09-09`): the required Ajv `8.17.1` baseline is
covered by GHSA-2g4f-4pwh-qvx6 only when its optional `$data` mode is enabled.
This harness explicitly sets `$data: false` and accepts only repository-owned
schemas. No audit suppression is configured; re-evaluate the pin during SS-06
or before accepting untrusted schemas. A `js-yaml` `4.3.2` override removes the
high-severity advisory otherwise inherited through Redocly.

To regenerate the accepted transport declarations after an intentional
contract change:

```bash
npm run generate:transports
```
